# Магазин с системой ролей

## Описание проекта
Веб-приложение для управления товарами с системой контроля доступа на основе ролей.

## Технологии
- **Бэкенд**: Node.js, Express, JWT, bcrypt
- **Фронтенд**: React, Vite, Axios, React Router

## Функционал

### Аутентификация
- Регистрация пользователей с выбором роли
- Вход в систему с JWT токенами
- Обновление access-токена через refresh-токен
- Выход из системы

### Роли и права доступа

| Роль | Права |
|------|-------|
| **Гость** (неавторизован) | Только регистрация и вход |
| **Пользователь** | Просмотр товаров |
| **Продавец** | Создание и редактирование своих товаров |
| **Администратор** | Управление товарами (все) + управление пользователями |

### API Endpoints

#### Аутентификация
| Метод | URL | Доступ | Описание |
|-------|-----|--------|----------|
| POST | /api/auth/register | Гость | Регистрация |
| POST | /api/auth/login | Гость | Вход |
| POST | /api/auth/refresh | Гость | Обновление токенов |
| POST | /api/auth/logout | Авторизованные | Выход |
| GET | /api/auth/me | Авторизованные | Текущий пользователь |

#### Пользователи (только admin)
| Метод | URL | Описание |
|-------|-----|----------|
| GET | /api/users | Список пользователей |
| GET | /api/users/:id | Пользователь по ID |
| PUT | /api/users/:id | Обновление пользователя |
| DELETE | /api/users/:id | Блокировка пользователя |
| POST | /api/users/:id/unblock | Разблокировка пользователя |

#### Товары
| Метод | URL | Доступ | Описание |
|-------|-----|--------|----------|
| GET | /api/products | User, Seller, Admin | Список товаров |
| GET | /api/products/:id | User, Seller, Admin | Товар по ID |
| POST | /api/products | Seller, Admin | Создание товара |
| PUT | /api/products/:id | Seller (свои), Admin | Обновление товара |
| DELETE | /api/products/:id | Admin | Удаление товара |
