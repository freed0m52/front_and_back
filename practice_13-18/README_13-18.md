# Создание PWA-приложения Мои заметки

## Практика 13 Service Worker

Реализована регистрация Service Worker, кэширующая статические ресурсы (html, css, js) при первом посещении. Приложение загружается при отсутствии интернета благодаря перехвату fetch-запросов. Заметки сохраняются в localStorage и остаются доступными офлайн

## Практика 14 Web App Manifest

Создан файл manifest.json с указанием имени, иконок разных размеров и режима отображения. в index.html добавлены мета-теги для мобильных устройств (Android и IOS), что позволяет установить приложение на устройство. При установке приложение запускаетя в отдельном окне без элементов браузера 

## Практика 15 HTTPS + App SHell

Настроенлокальный https-сервер с помощью mkcert для корректной работы push уведомлений. Реализована архитектура App Shell: каркас (шапка, меню) загружается моментально из кэша, а контент подгружается динамически. Переключение между страницами происходит без перезагрузки

## Практика 16 Web Socket + Push

Подключена библиотека Socket.IO для двусторонней связи в реальном времени. При добавлении заметки уведомление моментально появляется у клиента. Реализованы push-уведомления через VAPID-ключи: После подписки пользователь получает системные уведомления Windows даже при свёрнутом браузере

## Практика 17 Детализация Push

Добавлена форма для создания заметок с напоминанием (текст + дата и время). На сервере реализовано планирование push-уведомлений. В уведомление добавлена кнопка "Отложить на 5 минут", которая отправляет запрос на сервер и переносит напоминание. Напоминания работают даже при свёрнутом браузере


## Вывод

В результате выполнения практических занятий 13-17 разработано полноценное PWA-приложение для заметок. Оно поддерживает офлайн-режим, устанавливается на устройство, обменивается сообщениями в реальном времени через WebSocket и отправляет push-напоминания с возможностью откладывания. Все ключевые технологии современной веб-разработки (Service Worker, Manifest, App Shell, WebSocket, Push) успешно интегрированы и протестированы
